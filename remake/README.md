### ① 進行波の波形 — `traveling.html`

パルスや連続波が右へ進むようすを見せるツールです。

- 波形1／波形2：手が1回振って、半波長のパルスが右へ進む（上向き・下向き）
- 波形3：振り続けて、5波長の波列が通り過ぎる
- 連続波：途切れない正弦波
- 緑球／赤球／青球／赤･青球：媒質の位置に玉を置く（赤はλごと、青はλ/2ずれた位置）
- 波長 −＋／振動数 −＋：λ（200〜1200）と周期 T（16〜3の8段階）を変更。速さ v = fλ は自動で決まります

### ② 波と媒質の振動 — `oscillation.html`

上に y–x グラフ（波形そのもの）、下に y–t グラフ（選んだ媒質1点の変位の記録）を並べます。波がその点を通り過ぎると、その点の上下運動が下のグラフにペンで描かれていきます。

- 媒質１〜４：注目する点を λ/4 ずつずらして選ぶ
- スタート：波を動かし始める
- パルス波／正弦波／連続波：波の来かたを変える
- 振幅反転：波の山と谷を上下逆にする
- 波長 −＋：λ（200〜800）を変える。**上の y–x グラフだけ**が変わります
- 振動数 −＋：周期 T（16〜4の7段階）を変える。**下の y–t グラフだけ**が変わります

y–t グラフの横軸は時間なので、波長を変えても周期の幅は変わりません。逆に、振動数を変えても波形の波長は変わりません。「波長と周期は別のもの」がそのまま目で見えます（初期設定では、たまたま両者が同じ幅になるようにそろえてあります）。

### ③ 波の合成と定常波 — `composite-wave.html`

左から進む波（青）と右から進む波（赤）を重ね合わせ、その和である合成波（緑）を描きます。

- パルス１（正弦の山）／パルス２（く形波）：2つのパルスがすれ違う
- 正弦波／進行波：先端のある波、または最初から続いている波
- 定常波：腹（赤玉）と節（青玉）の目印つき
- 合成波／入射波／入射波･合成波：表示の切り替え
- 同位相／逆位相：右から来る波の山と谷をひっくり返す

く形波は、ぴったり重なった瞬間に合成波が同位相でちょうど2倍、逆位相でちょうど0になります。

### ④ 縦波と横波表示 — `longitudinal.html`

上に実際の縦波（媒質そのものが左右に振動するようす）、下に横波表示（媒質の変位を縦にとったグラフ）を並べます。同じ位置どうしが縦線でつながっているので、実際の疎密の位置と、横波表示の形の対応が読み取れます。

- 進行波：疎密が右へ進んでいく
- 定常波：節では媒質が動かず、節のところで疎密ができる
- 変位の矢印：一つひとつの媒質が、もとの位置からどちら向きにどれだけ動いたかを矢印で表示（右向き＝赤、左向き＝青）
- 変換のしくみ：横波表示ができる手順を、止めたまま1段階ずつ見せる

横波表示のグラフが下がりながら軸を横切るところが「密」になります。

**変位の矢印**を出すと、上段は「もとの位置（細い輪）→ いまの位置」への横向きの矢印、下段は同じ変位を縦向きにした矢印になります。上下で矢印の色と長さが一致するので、横向きの変位が縦軸の値になっていることが目で追えます。定常波では、節の媒質にだけ矢印が出ないことがはっきり分かります。

**変換のしくみ**（最初から／もどす／1個すすめる／最後まで）

1. 媒質はもともと等間隔に並んでいる
2. 変位を横向きの矢印で表す（右向き＝赤、左向き＝青）
3. 矢印を左から1個ずつ 90° 回して縦向きにする（右→上、左→下）。回転の軌跡を点線の円弧で見せます
4. 矢印の先を結ぶと、横波表示のグラフになる

媒質は1波長ぶん17個。「1個すすめる」で発問をはさみながら手動で進められます。

### ⑤ 波の反射（自由端・固定端） — `reflection.html`

右から来る端で波が反射するようすです。入射波（青）・反射波（赤）・その和である合成波（緑）を描きます。

- 自由端／固定端：端の種類を変える。どちらも端は縦の棒で表し、違いは端での波のふるまいそのもので見せます
- パルス波：山ひとつ（半波長）を送って、反射して戻るまでを見る
- 正弦波：2波長ぶんの波列を送る
- 正弦波･連続：途切れない波を送り続けて、定常波ができていくところを見る
- 定常波：最初からできあがった定常波。腹（赤玉）と節（青玉）の目印つき
- 合成波／入射波／入射･反射波／入射･反射･合成波：表示の切り替え（作図の練習用）

反射波は**折り返し（鏡像法）**で描いています。端の向こうへそのまま進んだと考えた入射波をうすい青で残してあるので、それを端で折り返したものが赤い反射波になっていることが目で追えます。自由端は折り返すだけ、固定端は折り返して上下も反転します。

そのため、山がちょうど端に届いた瞬間に、固定端では入射波と反射波が打ち消し合って媒質全体が平らになり、自由端では変位が2倍になります。定常波では、自由端が腹・固定端が節になります。

### ⑥ 波の干渉 — `interference.html`

2つの波源から出た波が重なると、いつも大きく揺れる所と、まったく揺れない所ができます。それが2つの波源からの距離の差（経路差）だけで決まることを見せるツールです。モードが2つあります。

**経路差モード**（最初の画面）— 波源 A・B から点 P までの道のりに沿って、波をそのまま描きます。

- 経路差 0／0.5λ／λ／1.5λ／2λ／2.5λ のボタンで、その経路差になる位置に点 P が移ります
- A→P・B→P の道のりの長さは、それぞれの経路に沿った寸法線に「3.39 λ」のように大きく出ます
- 道すじが斜めでも**変位はいつも上下方向**にとってあるので、点 P に届いた2つの波の高さをそのまま見くらべられます
- 点 P には 0・±A・±2A の**目盛り**があります。そこに3つの印が出ます
  - 青い輪 … 波源 A から来た波の高さ
  - 赤い点 … 波源 B から来た波の高さ
  - 緑の点 … 2つを重ね合わせた結果
- 経路差が λ の整数倍のときは、青い輪の中に赤い点がぴったり収まったまま動きます（＝いつも同じ高さで届く）。緑の点はその2倍の高さまで振れます
- 経路差が半整数倍のときは、青が上なら赤は下と、いつも真逆になります。緑の点は目盛りの 0 から動きません
- 波源の赤い丸も上下に振動します。同位相なら2つは同じ動き、逆位相なら逆向きの動きになります

**水面波モード** — 同じことを水面全体で見た図です。表示のしかたを2つから選べます。

- **リアルな水面**（既定）：水面の傾きから光の当たり方を計算して陰影をつけた表示です。斜めから光を当てた本物の水面のように見えます
- **波面（作図）**：教科書の作図と同じく、山＝実線・谷＝破線の同心円で描きます。円は外へ広がっていきますが、強め合う点（緑●）・弱め合う点（ピンク○）はその場から動きません

「強め合う／弱め合う」の表示は既定でオフです。ボタンで、強め合う所（作図では点、リアルな水面では緑の線）・弱め合う所（ピンクの線／点）を重ねて表示できます。

共通の操作：

- 波源の距離 −＋：1λ 〜 3λ を 0.5λ きざみで変えられます。距離を大きくすると干渉の縞が増えます
- 波長 −＋：波長そのものを6段階で変えられます。短くすると円（波面）の間隔が詰まり、長くすると広がります
- 強め合う／弱め合う：表示のオン・オフ（既定はオフ。作図では点の表示、リアルな水面では双曲線を重ねて表示）

同位相の波源では、経路差が λ の整数倍なら強め合って振幅が2倍に、半整数倍なら打ち消し合って0になります。逆位相の波源では、この2つがそっくり入れかわります。
